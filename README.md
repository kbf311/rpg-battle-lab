# RPG バトルラボ (RPG Battle Lab)

ブラウザで手軽に遊べる、カード選択型のターン制コマンドバトルRPGです。  
フレームワークやビルドツールを使わず、HTML/JavaScript/CSSだけで動作します。個性豊かなキャラクターとスキルカードを駆使して、強大な魔王を討伐しましょう！

---

## 🎮 ゲーム概要

プレイヤーは3人の個性的な勇者（？）から1人を選び、難易度を選択して魔王との1対1のバトルに挑みます。  
毎ターン配られる4枚のスキルカードから最善の1枚を選択し、攻撃・魔法・バフ・回復・妨害などを駆使して勝利を目指します。

- **ジャンル**: ターン制カードバトルRPG
- **プレイ人数**: 1人
- **プレイ環境**: PC推奨（最新の Google Chrome, Microsoft Edge など）
- **インストール**: 不要（ダウンロードしてブラウザで開くだけ）

---

## 🚀 遊び方（クイックスタート）

1. **ゲームの開始**  
   リポジトリ内の `index.html` をブラウザで直接開きます（ダブルクリックでOK、Webサーバー不要）。
2. **キャラクター選択**  
   3人のキャラクター（イゾルテ / ヴォルガド / ルナティ）から使用するキャラクターを1人クリックして選択します。
3. **難易度選択**  
   「簡単」「普通」「難しい」から挑戦したい難易度を選びます。
4. **「バトル開始」をクリック**  
   バトル画面へ遷移し、魔王との決戦が始まります。
5. **カードを選んでターン進行**  
   画面下部に提示された4枚のスキルカードから1枚をクリックして行動します。  
   プレイヤー行動後、魔王が反撃を行い、次のターンへ進みます。

## 😈 難易度設定

挑戦する難易度に応じて、立ちはだかる魔王の能力が変化します。

- **簡単 (Easy) -「ザコ魔王」**  
  HP 10,000 / MP 500。まずはバトルの流れやカード効果を掴みたい方向け。
- **普通 (Normal) -「魔王」**  
  HP 32,767 / MP 1,000。しっかりとした戦略とリソース管理が求められる標準難易度。
- **難しい (Hard) -「スーパー魔王」**  
  HP 65,535 / MP 9,999 / 幸運 500。圧倒的な耐久力に加え、魔王自身も高幸運から凶悪な高レアスキルを連発してくる超激辛難易度。

## ⚔️ バトルシステム

### 1. ターン進行ルール
1. 手札に表示されている4枚のスキルカードから1枚を選択します。
2. プレイヤーのスキルが発動し、ダメージやバフ・デバフ、回復効果が適用されます。
3. 魔王が生存している場合、魔王がスキルカードをランダムに選んで反撃してきます。
4. ターン終了時に新しいスキルカードが4枚配られ、次のターンに移ります。
5. 魔王のHPを0にすると**勝利**、プレイヤーのHPが0になると**敗北**となります。

### 2. リロール（手札引き直し）機能
- 手札の4枚が気に入らない場合、画面上部の「🎲 リロール」ボタンを押すと、**ターンを消費せずに手札を4枚引き直す**ことができます。
- 初期回数は **3回** です。
- **10ターン経過するごとにリロール回数が1回回復**します。ピンチの時や大技を狙いたい時に戦略的に活用しましょう。

### 3. スキルカードとレアリティ
カードには5段階のレアリティが存在します。

| レアリティ | バッジ色 | 特徴 |
| :--- | :--- | :--- |
| **コモン (Common)** | グレー | 基本攻撃・初歩魔法・基礎トレーニングなど安定した基本技 |
| **アンコモン (Uncommon)** | グリーン | 中級攻撃技やステータス強化技、自爆ロマン技など |
| **レア (Rare)** | ブルー | 上位攻撃魔法、自己回復、デバフ、MP削りなど戦局を動かす技 |
| **エピック (Epic)** | パープル | 超強力な大技や全体強化、全快級ヒールなど戦況を一変させる技 |
| **レジェンダリー (Legendary)** | ゴールド | 神話級の極大ダメージ、因果律操作、黒歴史暴露など圧倒的効果の切り札 |

### 4. 幸運度（Luck）とカード抽選
- 手札に配られるカードのレアリティは、キャラクターの「幸運度」によって決定されます。
- 幸運度が高いほどダイスを振る回数が増え、最も良い結果が採用されるため、**エピックやレジェンダリーなどの高レアリティカードが出現しやすく**なります。
- バトル中に幸運度を上げるスキルを使うことで、後半の手札の質を劇的に高めることができます。

### 5. リソース管理（HP & MP）
- 一部の強力な魔法スキルは **MP** を消費します。MPが不足しているとスキルは不発（失敗）となります。
- 強力な回復スキルや「瞑想」「仮眠」などのMP回復スキルを活用してリソースを枯渇させない立ち回りが重要です。
- 中には **HP** を代償に発動する超高火力技や、成功率が低い代わりに当たれば一撃必殺の博打スキルも存在します。

## 💡 攻略のヒント (Tips)

1. **ヴォルガド攻略法**:  
   物理攻撃バフ（筋トレなど）を重ねてから強力な剣技を叩き込む正攻法が有効。手堅くHP管理を行いましょう。
2. **イゾルテ攻略法**:  
   初手から高火力魔法を連打して短期決戦を狙うか、MPを補給しつつエピック以上の魔法で一気にケリをつけましょう。HPが低いため被弾には注意が必要です。
3. **ルナティ攻略法**:  
   最初から高レアカードを引きやすいため、一撃必殺技やレジェンダリースキルの発動を狙うのが爽快です。さらに幸運バフを積めば奇跡のような手札が連発します。
4. **MP削り戦略**:  
   「精神攻撃」や「黒歴史の暴露」などで魔王のMPをゼロにしてしまえば、魔王は強力な魔法攻撃を放てなくなります。
